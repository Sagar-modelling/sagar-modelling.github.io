This repository contains the source code for my personal portfolio website hosted on GitHub Pages. 

### 🌐 Live Website: [https://sagar-modelling.github.io](https://sagar-modelling.github.io)

## 🚀 Tech Stack
- **HTML5** (Semantic Structure)
- **Vanilla CSS3** (Custom Dark Theme & Glassmorphism)
- **Vanilla JavaScript** (Typewriter Effect & Scroll Animations)

## ⚡ Features
- **Dynamic Typing Animation:** Showcasing various AI & MLOps roles.
- **Glassmorphism Design:** Ultra-premium frosted glass UI components.
- **Intersection Observer:** Smooth fade-in scroll animations for all sections.
- **Fully Responsive:** Optimized for both desktop and mobile viewing.
